## v2.1.0-improved - 2026-08-28
### Changed
* perf: optimize Google Photos metadata matching from O(n²) to O(n) for large takeout imports
* perf: optimize sidecar file discovery using map-based case-insensitive lookup
* perf: optimize CSV report generation using strings.Builder instead of concatenation
* docs: document Go 1.26 baseline and changie contribution workflow
* perf: optimize sanitizeTitle by pre-compiling regex
* perf(exif): use sync.Pool for metadata reading buffers to reduce memory allocations
* perf: optimize Google Photos metadata matching using binary search, significantly improving performance for large directories
* refactor: encapsulate DateRange fields After and Before with getter methods
* perf: optimize iCloud takeout browsing by avoiding redundant double scan
* Parallelize asset discovery pagination and fix data race in progress tracking
* perf: Optimize DeleteAssets calls by batching them per group in the stack command
* perf(exif): reduce string passes in direct metadata parsing
* perf: optimize RemoveAsset in internal/assets/group.go from O(N) to O(1) using swap-with-last
* feat: support Immich v3 while retaining v2.7 compatibility
